# Module 5.5 — АЦП + два програмні фільтри, порівняння

За основу взято код чистого зчитування АЦП з `module3.1` (потенціометр на GPIO10,
ADC1 CH9, з калібруванням у мВ, без жодної фільтрації). До того самого потоку
сирих відліків додано два незалежні програмні фільтри:

1. **SMA** (Simple Moving Average) — ковзне середнє по вікну фіксованого розміру
   (`SMA_SIZE = 10` відліків, 500 мс).
2. **EMA** (Exponential Moving Average) — експоненційне згладжування
   (`EMA_ALPHA = 0.2`).

## Чому саме ці два фільтри й ці параметри

Щоб порівняння було чесним, обидва фільтри налаштовані на приблизно однакову
*ефективну* довжину вікна. Для EMA ефективна кількість врахованих відліків:

```
N_eff = (2 − alpha) / alpha
```

При `alpha = 0.2`: `N_eff ≈ 9`, що близько до вікна SMA (`10`). Тобто обидва
фільтри "усереднюють" приблизно однакову кількість останніх відліків — різниця
не в об'ємі згладжування, а в його формі:

- **SMA** — прямокутне вікно: усі 10 останніх відліків мають однакову вагу,
  найстаріший відлік різко "випадає" з вікна на наступному кроці.
- **EMA** — вага спадає експоненційно: найновіший відлік має найбільший вплив,
  старі відліки не зникають різко, а поступово втрачають вагу.

## Що вимірюється й друкується

Кожен відлік — один рядок таблиці: `N, RAW, SMA, EMA` (сирі коди) та
`RAW_mV, SMA_mV, EMA_mV` (переведено через калібрування АЦП).

Раз на `NOISE_WINDOW = 40` відліків (~2 с) друкується рядок `STATS` з
об'єктивною мірою шуму — середнім модулем різниці сусідніх відліків
(`mean|x[k] − x[k-1]|`) окремо для RAW, SMA, EMA, і відсотком зменшення
відносно RAW:

```
STATS  mean|delta| raw=12.40  sma=2.10 (-83%)  ema=3.85 (-69%)
```

## Як порівнювати наживо

- **Потенціометр нерухомий** → дивимось на `STATS`: обидва фільтри повинні
  суттєво зменшити `mean|delta|` порівняно з RAW (шум АЦП/дроту придушується).
  Очікується, що SMA дає трохи менше залишкового шуму за EMA при однаковому
  `N_eff`, бо прямокутне вікно повністю "забуває" старі викиди, тоді як EMA
  ще якийсь час несе їхній слід (хоч і з малою вагою).
- **Потенціометр швидко крутимо** (стрибок значення) → SMA реагує зі сходинками
  й помітною затримкою (поки нове значення не заповнить усе вікно), EMA починає
  рухатись одразу, але доганяє ціль поступово (експоненційний "хвіст").
  Це та сама причина, чому в `module3.2` (SMA + гістерезис для LDR) вибір падав
  саме на SMA — передбачувана, обмежена затримка зручніша для порогового
  рішення "світло/темрява", ніж "довгий хвіст" EMA.
- Для візуального порівняння в реальному часі: `tools/serial_plotter.py COM3`
  малює RAW/SMA/EMA одним графіком за номером відліку — видно і придушення
  шуму на пласкій ділянці, і форму відгуку фільтра на різкий стрибок.

## Підсумок порівняння

| Критерій                          | SMA                          | EMA                                 |
|------------------------------------|-------------------------------|--------------------------------------|
| Форма вагового вікна               | прямокутна (жорстка межа)     | експоненційна (плавне забування)     |
| Пам'ять / зберігання               | буфер на `SMA_SIZE` відліків  | 1 float (попереднє згладжене значення) |
| Затримка на різкий стрибок         | "сходинка", доки вікно не заповниться новим значенням | миттєвий початок руху, повільне доганяння цілі |
| Придушення випадкового шуму        | трохи краще при однаковому N_eff | трохи гірше, "довгий хвіст" від старих викидів |
| Обчислювальна вартість             | O(1) на відлік, потребує буфер | O(1) на відлік, без буфера            |

Обидва фільтри — не заміна апаратного RC-фільтра з `module5.3`/`module5.4`,
а доповнення до нього: програмний фільтр працює вже з дискретизованими
відліками й не може прибрати те, що вже "заеліасилось" при вибірці, але добре
згладжує залишковий шум АЦП і дрижання від нестабільного контакту повзунка.

## Апаратна конфігурація

| Сигнал              | Пін ESP32-S3 | Примітка                         |
|---------------------|--------------|-----------------------------------|
| Потенціометр (wiper)| GPIO10       | ADC1, канал 9, атенюація 12 дБ    |
